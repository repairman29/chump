# ChumpOS organ manifest — desired systemd state on the PRIMARY node (helsinki).
#
# The single repo-declared source of truth for which ChumpOS organs must be
# RUNNING and which auto-pagers must stay OFF. scripts/ops/organ-reconcile.sh
# reads this file and makes the node's live systemd state match it — the first
# slice of reproducible-deploy (RESILIENT-305 / RESILIENT-000 self-healing).
#
# WHY THIS FILE EXISTS (2026-08-13 incident): auto-pager DM spam kept
# resurrecting because failed organs were hand-managed and install-helsinki-atc
# re-enabled them every 5 min; the fix landed as HOST-LEVEL systemd drop-ins
# (/etc/systemd/system/*.d/zz-autopage-off.conf) — a NEW snowflake invisible to
# the repo, and the deploy mirror's `git reset --hard origin/main` silently
# reverts any working-tree fix. Declaring desired state HERE, in the repo, and
# having the reconcile re-apply it on a timer converges the node to the repo
# automatically and survives the reset.
#
# Format: one directive per line, "<state>  <unit>". Blank lines and lines
# beginning with '#' are ignored. Two states:
#
#   enabled     <unit>  → this organ must be enabled AND active. The reconcile
#                         runs `systemctl enable --now <unit>` if it is not
#                         already active. (A no-op when it already is.)
#
#   paging_off  <unit>  → this is an auto-pager that MUST stay silent. The
#                         reconcile installs a repo-declared drop-in
#                         (/etc/systemd/system/<unit>.d/zz-organ-reconcile-pager-off.conf)
#                         that neuters ExecStart to /bin/true, then stops the
#                         service if it is running. The drop-in wins over the
#                         tracked/host unit's ExecStart, survives
#                         install-helsinki-atc.sh's `cp -f` of the base unit
#                         (the .d/ dir is untouched) AND survives the mirror's
#                         `git reset --hard` (its content is re-applied from
#                         this repo, not a one-time host edit).

# --- Auto-pagers that must stay OFF (2026-08-13 operator DM-spam loop) --------
# heartbeat-monitor pages node_heartbeat_incomplete for the (known) closetjunky
# -down condition; sla-scorecard + board-ceo-briefing page merge-SLA/CEO beats.
# All three are neutered until re-enabled deliberately in this manifest.
paging_off  chump-heartbeat-monitor.service
paging_off  chump-sla-scorecard.service
paging_off  chump-board-ceo-briefing.service

# --- Organs that must be running ---------------------------------------------
# chump-discord-gateway: the two-way operator channel (must not go dark).
# chump-pr-lander.timer: arms green PRs so they merge (RESILIENT-288).
# NOTE: chump-organ-reconcile.timer (this reconcile's own beat) is intentionally
# NOT self-listed here — its liveness is install-helsinki-atc.sh's job (run on
# every deploy + boot), same as every other ATC timer. Clean separation: the
# installer keeps the timer alive, the timer runs the reconcile, the reconcile
# enforces this manifest.
enabled     chump-discord-gateway.service
enabled     chump-pr-lander.timer
# chump-ci-flake-rerun.timer: the CI-flake self-heal organ (RESILIENT-306).
# Reruns known-flaky red required-checks on open fleet PRs so a flaky test
# (e.g. credible218) cannot jam the merge queue; escalates real failures once
# instead of looping. Declared here so reconcile re-arms it if it drifts/fails
# (it sat in `failed` all night on 2026-08-13 — a SIGPIPE bug, now fixed).
enabled     chump-ci-flake-rerun.timer
# chump-pr-approval.timer: the approve-from-phone SURFACER (RESILIENT-265).
# Detects OS-authored PRs on external product repos (default repairman29/olive)
# that need Jeff's approval and DMs each to his phone with ✅ Merge / ❌ Reject
# buttons; the gateway acts on the tap. Declared here so reconcile re-arms it if
# it drifts or fails. (Detection only — it NEVER merges without a real tap.)
enabled     chump-pr-approval.timer
# chump-farmer.timer: the persistent farmer runner (RESILIENT-313). Fires the
# farmer tick every 30s so the worker-gate heartbeat (RESILIENT-069) never crosses
# its 120s stale threshold — the fix for the recurring silent fleet-stall. Retires
# the fragile, hand-installed transient `chump-farmer-bridge` unit. Declared here
# so organ-reconcile re-arms it if it drifts or fails.
enabled     chump-farmer.timer
# chump-rot-reaper.timer: the CONFLICTING-PR drain (RESILIENT-324). Closes open
# PRs that are genuinely CONFLICTING and older than the age gate — the ones the
# armed-rebaser CANNOT rebase — and re-queues their gaps to be redone on fresh
# main. Without it the back-pressure breaker's stuck-pile drains only to 4–5 and
# the fleet stays halted in the hysteresis dead-zone with no auto-recovery (the
# 2026-08-14 hours-long deadlock). Declared here so organ-reconcile re-arms it if
# it drifts or fails.
enabled     chump-rot-reaper.timer
# chump-integrator.timer: the Batched Merge Train (RESILIENT-318 / INFRA-2130).
# Batches up to 5 ready_to_ship gaps through a preflight gate into ONE
# integration branch so CI runs once per batch instead of once per gap
# (~7 -> ~35 PRs/hr). A Mac-launchd-only organ ported to systemd. Runs DRY-RUN
# (CHUMP_INTEGRATOR_LIVE=0 in the unit): it selects + preflights + logs what it
# WOULD ship, no push/PR — SAFE to keep enabled while the fleet is paused.
# Flipping LIVE is a separate operator decision gated on trunk-GREEN
# (docs/process/SCALING.md). Declared here so organ-reconcile re-arms it if it
# drifts or fails.
enabled     chump-integrator.timer

# chump-backlog-sync-writer.timer: the registry single-writer (CREDIBLE-292,
# design RESILIENT-194). Publishes .chump/state.sql to origin/main every
# 15 min so every node's `--reader` and the cluster-unique reserve() check
# (fetch-origin-before-git-history-check) see current truth. Designed but
# never installed on any node until CREDIBLE-292 — a dead writer here is
# exactly how the 2026-08-15 registry split-brain (duplicate IDs across
# helsinki/mac) went undetected for 21 days. Freshness is independently
# checked by fleet-doctor-strict.sh's backlog-sync-freshness check (RED if
# origin/main .chump/state.sql goes >24h stale). Declared here so
# organ-reconcile re-arms it if it drifts or fails.
enabled     chump-backlog-sync-writer.timer
