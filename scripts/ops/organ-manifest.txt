# ChumpOS organ manifest — desired systemd state on the PRIMARY node (helsinki).
#
# The single repo-declared source of truth for which ChumpOS organs must be
# RUNNING and which auto-pagers must stay OFF. scripts/ops/organ-reconcile.sh
# reads this file and makes the node's live systemd state match it — the first
# slice of reproducible-deploy (RESILIENT-305 / RESILIENT-000 self-healing).
#
# WHY THIS FILE EXISTS (2026-08-13 incident): auto-pager DM spam kept
# resurrecting because failed organs were hand-managed and install-helsinki-atc
# re-enabled them every 5 min; the fix landed as HOST-LEVEL systemd drop-ins
# (/etc/systemd/system/*.d/zz-autopage-off.conf) — a NEW snowflake invisible to
# the repo, and the deploy mirror's `git reset --hard origin/main` silently
# reverts any working-tree fix. Declaring desired state HERE, in the repo, and
# having the reconcile re-apply it on a timer converges the node to the repo
# automatically and survives the reset.
#
# Format: one directive per line, "<state>  <unit>  [role=ROLE] [requires=SPEC,SPEC,...]".
# Blank lines and lines beginning with '#' are ignored. Two states:
#
#   enabled     <unit>  → this organ must be enabled AND active. The reconcile
#                         runs `systemctl enable --now <unit>` if it is not
#                         already active. (A no-op when it already is.)
#
#   paging_off  <unit>  → this is an auto-pager that MUST stay silent. The
#                         reconcile installs a repo-declared drop-in
#                         (/etc/systemd/system/<unit>.d/zz-organ-reconcile-pager-off.conf)
#                         that neuters ExecStart to /bin/true, then stops the
#                         service if it is running. The drop-in wins over the
#                         tracked/host unit's ExecStart, survives
#                         install-helsinki-atc.sh's `cp -f` of the base unit
#                         (the .d/ dir is untouched) AND survives the mirror's
#                         `git reset --hard` (its content is re-applied from
#                         this repo, not a one-time host edit).
#
# RESILIENT-347 (per-node-applicable reconcile): `enabled` lines may declare
# two optional fields, space-separated after the unit name:
#
#   role=brain|muscle|data   Informational classification of what the organ
#                            does (brain=decision/coordination, muscle=acts on
#                            the world e.g. merges/pushes, data=publishes
#                            state). Surfaced on every applicability/backoff
#                            ambient event so an operator can see WHICH class
#                            of organ is dark on a given node. Defaults to
#                            "brain" if omitted.
#
#   requires=SPEC,SPEC,...   Comma-separated preconditions that must ALL hold
#                            on THIS node before the reconcile will even
#                            attempt to enable the organ. Missing a
#                            precondition is NOT an error — it means the organ
#                            is simply not applicable to this node (e.g. a
#                            Rust helper binary that isn't built there yet),
#                            and the reconcile skips it silently (one
#                            organ_reconcile_not_applicable event, no retry
#                            churn). Supported spec kinds:
#                              bin:<name>   `command -v <name>` must succeed
#                              env:<VAR>    $VAR must be a non-empty env var
#                              dep:<unit>   another systemd unit must already
#                                           be active
#
# Applicability is the FIRST gate (blast-all -> per-node-applicable, was
# RESILIENT-347's core ask). If an organ IS applicable but `enable --now`
# either fails outright or the unit is not verified active a few seconds
# later, the reconcile does NOT leave it to fail identically every single
# cycle (the pre-347 churn that re-installed 4 broken units every 5 minutes
# on CJ: integrator/sla-scorecard/backlog-sync-writer/farmer). Instead it
# disables the unit and records a cooldown backoff
# ($CHUMP_ORGAN_RECONCILE_BACKOFF_DIR/<unit>.json, default 1h via
# CHUMP_ORGAN_RECONCILE_BACKOFF_COOLDOWN_S) so the SAME broken unit is only
# retried once the cooldown expires, not every tick.
