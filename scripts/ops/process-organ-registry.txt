# process-organ-registry.txt — INFRA-3650 (PEER-HEAL-03, MISSION-010)
#
# Raw background bash processes that are NOT systemd units (or any other
# host-native supervisor) and therefore need their own revive muscle:
# scripts/ops/process-organ-heal.sh reads this file every cycle, checks
# liveness via svc_is_alive (pgrep -f "organs/<name>.sh"), and respawns
# anything missing via svc_revive (launches ~/.chump/organs/<name>.sh).
# This is the process-level sibling of scripts/ops/organ-manifest.txt (which
# organ-reconcile.sh reads for chump-*.service/.timer units) — same "declare
# desired state in the repo, let a heal loop enforce it" shape, one level
# below systemd.
#
# Format: one organ per line, "<name>|<script-path-relative-to-repo-root>[|<args>]".
# Blank lines and lines starting with '#' are ignored.
#
#   name          short identifier — used as the organ name for svc_is_alive /
#                 svc_revive (INFRA-3723). The organ script must be installed
#                 at ~/.chump/organs/<name>.sh (done by chump-node-install.sh).
#   script-path   path relative to REPO_ROOT (informational; the heal loop
#                 delegates to svc_* which uses the ~/.chump/organs convention).
#   args          optional, appended to the respawn command verbatim

# almanac-vision-keeper: the "eyes" (INFRA-3650) — a standing loop around
# almanac-liveness-refresh.sh (INFRA-3643/TREK-17). Before this gap it either
# didn't run as a standing process at all, or ran as a bare bash process
# started by hand with nothing watching it — dies silently, the node's
# fusion-search index goes stale, and nobody notices until someone asks
# almanac a question that comes back wrong. Declaring it here is what lets
# process-organ-heal.sh revive it, the same way organ-manifest.txt lets
# organ-reconcile.sh revive a dead systemd unit.
