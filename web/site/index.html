ATOMIC OWNERSHIP

File & Symbol-Region Leases

Claim whole directories (crates/chump-ship/*) or individual Rust symbols (src/auth.rs::verify_token). Conflicting commits from sibling agents are rejected at pre-commit before a stomp ever enters git history.

[chump hook pre-commit] BLOCKED
staged file src/auth.rs is leased by active session worker-02 (expires in 14m).

WORKFLOW GATE FIREWALL

Agents Never Self-Approve CI or Hooks

chump-ship compiles a non-overridable list of protected gate globs. If an agent modifies GitHub Actions workflows, CI scripts, or git hooks, the PR opens—but auto-merge arming fails closed for human review.

Protected compile-time globs:
.github/workflows/* · scripts/ci/* · scripts/git-hooks/* · crates/chump-preflight/*
