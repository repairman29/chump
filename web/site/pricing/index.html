Licensing & Commercial Use Q&A

Can my company use Chump internally to build proprietary closed-source software for $0?
Yes. Running Chump internally on your developer laptops, workstations, or private CI servers to write your company's proprietary code does not trigger AGPL-3.0 copyleft on the repositories Chump edits. Your application code remains 100% yours under whatever license you choose.
When does AGPL-3.0 apply, and why are 14 crates Apache-2.0?
AGPL-3.0 applies only if you modify Chump itself and host Chump as a network service for external users without sharing your Chump modifications—preventing cloud providers from wrapping Chump as a closed SaaS. Meanwhile, 14 standalone building-block crates on crates.io carry permissive Apache-2.0 licenses so any Rust project can embed them freely.
