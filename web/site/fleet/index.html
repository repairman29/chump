Technical Q&A

        
Fleet Coordinator Questions


        

          

            What happens when an agent process crashes mid-edit while holding a file lease?
            

              Every lease carries a heartbeat timestamp and TTL inside .chump-locks/. chumpd's pure-Rust lease_reaper organ scans every 60 seconds, verifies PID liveness via chump-pal, and reaps orphaned leases while preserving uncommitted worktree changes for inspection or --force-recover.
            

          

          

            Why SQLite WAL + JSON lockfiles instead of Postgres or a hosted SaaS coordinator?
            

              Zero infrastructure setup and air-gap survivability. SQLite with journal_mode=WAL and busy_timeout=5000 easily handles dozens of concurrent local workers on a single repo, works on an airplane with local Ollama, and leaves plain files you can inspect with sqlite3 or jq.
            

          

          

            Does Chump burn my GitHub GraphQL rate limit polling PR checks?
            

              No. Chump prioritizes a local SQLite webhook cache (.chump/github_cache.db, sub-100ms reads) and tags background calls with CHUMP_GH_CALL_CRITICALITY=background so dashboard scans automatically yield before ship-critical merges ever hit secondary rate limits.
            

          

          

            Can I use Chump on an existing repository without adopting the full autonomous daemon?
            

              Yes. Run chump config init and chump hook install in any git repo to get secret-blocking and file-lease pre-commit hooks immediately, then invoke chump gap reserve, chump claim, and chump ship manually whenever you spin up parallel agent tabs.
