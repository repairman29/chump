Step-by-Step Setup

Three commands to initialize any repository.

STEP 01 · INSTALL

Install the Single Rust Binary

Install via Homebrew on macOS, the standalone release scripts on Linux and Windows PowerShell, or Cargo on any OS. 

# macOS (Homebrew)
brew tap repairman29/chump && brew install chump

# Linux (prebuilt release)
curl --proto '=https' --tlsv1.2 -LsSf \
  https://github.com/repairman29/chump/releases/latest/download/chump-installer.sh | sh

# Windows (PowerShell prebuilt release)
powershell -ExecutionPolicy ByPass -c "irm https://github.com/repairman29/chump/releases/latest/download/chump-installer.ps1 | iex"

# Any OS from source via Rust Cargo
cargo install --git https://github.com/repairman29/chump chump --locked
STEP 02 · PROTECT REPO

Initialize State & Lease Hooks

Creates .chump/state.db (SQLite WAL) and installs native Rust pre-commit and pre-push guards that stop sibling agents from overwriting leased files or leaking secrets. 

cd /path/to/your-repo
chump init --yes
chump hook install && chump hook status
STEP 03 · CONNECT MODELS

Validate Auth & Launch Cockpit

Generate a starter ~/.chump/config.toml with 0600 permissions, verify your model slots, and start the supervisor or local web cockpit. 

chump config init && chump config validate
chump service install && chump up
chump --web --port 18440
Daily Workflow

Essential CLI commands. Local-first and scriptable.

Command What It Does
chump gap reserve --domain INFRA --title "Fix flaky test" --effort s Reserves a tracked task in .chump/state.db so parallel agents never pick duplicate work.
chump claim INFRA-001 --role target --paths "src/auth.rs" Atomically acquires a TTL file or symbol lease and creates an isolated git worktree + branch.
chump preflight Runs formatting, clippy, compile checks, and scoped tests locally in under 60s before pushing.
chump ship --gap INFRA-001 --mode manual Pushes the leased branch, opens a pull request, and blocks auto-merge if CI or hook files were touched.
chump onboard owner/repo --apply Scans an external repository, identifies concrete engineering tasks with file citations, and seeds the queue.
chump improve owner/repo --apply Runs the 4-stage autonomous loop: pick task, deduplicate, implement in an isolated worktree, and verify-merge.
chump external verify-merge --pr 42 --repo owner/repo --gap INFRA-001 Verifies GitHub CI is green and proves the PR's new test fails on base and passes on head before merge.
chump fleet level 0 Fail-closed hardware kill-switch (0 = immediate stop, 1–3 = supervised, 4–5 = autonomous).
